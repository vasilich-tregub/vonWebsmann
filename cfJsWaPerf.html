To not be blocked by CORS policy, this WASM demo should be run from http server. Python's http.server is good for testing purposes and can be launched with a command 
py -m http.server -b 127.0.0.1
  • The button 'Write to WASM' writes the bytes of the left input to the memory allocated in the 'dataView.wasm' module (see the line (memory (export "memory") 1)) in 'dataView.wat': 'dataView.wasm' is compiled from 'dataView.wat'.
  • The button 'Read from WASM' reads the bytes from the memory allocated by the 'dataView.wasm' module and displays the corresponding characters in the right control; if the source UTF16 string has no lone surrogates, the contents of inputs become identical.
  • The elapsed time is output with alerts. Examine the js code of write/read functions and compare the elapsed time of the two operations: the data transfer times are negligent as compared to the UI layout times.
